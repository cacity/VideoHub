## 类型判断

综合字幕、说话者、画面和声音判断，不要只看标题。

| 类型 | 常见证据 |
| --- | --- |
| `drama` | 人物对白推动事件，称谓和代词密集，镜头反打、动作和表情承担信息 |
| `podcast_interview` | 少数说话者长轮次发言，问题与回答清楚，画面变化少 |
| `documentary` | 旁白、采访、资料画面和现场声交替，事实与时间线较强 |
| `speech` | 单人持续陈述，有观点、例证和结论，现场画面变化有限 |
| `tutorial` | 步骤词、操作指令和结果验证密集，画面演示不可替代 |
| `news_commentary` | 事件背景、引用证据、判断和影响分析结构明显 |
| `vlog` | 第一人称经历、地点切换、环境声和行动过程较多 |
| `music_performance` | 歌唱或演奏占主体，歌词、节奏和表演画面决定结构 |
| `mixed` | 两种以上结构都很强，或证据不足以可靠归类 |

类型结果必须包含置信度和证据。主类型置信度低于 0.65 时使用 `mixed`。

## 类型策略

下表是初始范围，不是必须凑满的配额。“视觉片段”指没有对白字幕但对叙事有用的原片画面。

| 类型 | 叙事骨架 | 建议视觉片段比例 | 主要保留内容 |
| --- | --- | ---: | --- |
| `drama` | 人物－目标－阻碍－变化－结果 | 10%–25% | 反应、动作结果、空间关系、关键道具 |
| `podcast_interview` | 问题－观点－论据－结论 | 0%–8% | 完整问答、定义、关键例子 |
| `documentary` | 议题－证据－人物－转折－结论 | 10%–30% | 现场、档案、地点、人物活动 |
| `speech` | 主张－例证－解释－结论 | 0%–8% | 最清楚的论证和有记忆点的表达 |
| `tutorial` | 问题－准备－步骤－结果 | 0%–15% | 实际操作、界面变化、前后对比 |
| `news_commentary` | 发生了什么－为何发生－影响 | 5%–15% | 证据画面、数据、原始引用 |
| `vlog` | 目标－过程－意外－结果－感受 | 10%–30% | 地点、行动、反应和结果 |
| `music_performance` | 开场－发展－高潮－收束 | 20%–60% | 表演动作、观众反应、节奏完整性 |
| `mixed` | 选择最适合主线的结构 | 5%–20% | 对理解最有贡献的对白和画面 |

### 剧情类

- 不只剪“台词信息量高”的部分。人物沉默、眼神、动作结果可能比对白更重要。
- 反应镜头通常放在触发它的对白之后，除非原片明确使用悬念式提前展示。
- 保留必要的建立镜头，让观众知道人物在哪里、谁在与谁说话。
- 不把不同场景中的对白拼成一次连续对话。

### 播客和访谈

- 画面通常不是信息主体，优先确保问题和回答逻辑完整。
- 删除口头禅、重复和离题内容时，保留说话者语气和观点边界。
- 若打乱顺序，先补足名词和人物背景，避免“他、这件事、后来”失去指向。

### 教程

- 画面操作和语言步骤必须同步，不能把步骤顺序改到无法执行。
- 可压缩等待和重复操作，但结果画面必须对应真实操作。
- 无字幕演示段只在观众需要观察动作时保留。

### 纪录片、新闻和评论

- 区分原始事实、受访者陈述和作者判断。
- 时间线可为叙事重排，但成片不得让后发生的事看起来是前因。
- 数据、截图和引用应保留足够时长供阅读。

## 无字幕画面选择

候选片段通常取 1–6 秒。超过 8 秒必须说明它承担的叙事作用。

优先级：

1. 展示对白刚提到的人、地点、物体或结果。
2. 展示人物对关键事件的真实反应。
3. 建立场景空间或时间变化。
4. 缓冲两个语义或视觉差异较大的片段。
5. 为结尾提供自然收束。

排除：

- 黑帧、长时间静止、缓冲画面和技术故障。
- 与主线无关的片头、片尾、广告和重复素材。
- 只有字幕空档但没有视觉价值的等待。
- 会让人物关系、事件地点或时间产生错误理解的镜头。

## 重排风险

重排前逐项检查：

- 代词是否仍有明确指向。
- 人物是否在成片中已被介绍。
- 结论是否被放在证据之前且造成误解。
- 情绪反应是否仍对应正确触发事件。
- 问题和回答是否来自同一话题。
- 原片中的假设、引用或反问是否被误剪成作者结论。

## TTS 解说策略

- 解说先承担背景、时间跳转、因果连接和必要概括，不要逐句复述画面中已经清楚表达
  的对白。
- 关键对白、情绪反应、音乐起落和动作声前后保留无解说区间。原声整体可降到 30%，
  但仍要让观众听到素材本身，而不是只看画面配广播稿。
- 剧情解说应区分“画面事实”“人物台词”和“编辑解释”。无法由证据确认的动机用
  谨慎表述，不能写成确定事实。
- 播客和知识类内容优先保留最有辨识度的原声观点，TTS 用于压缩重复、补足上下文和
  连接重排后的段落。
- 解说字幕只显示实际播出的 TTS 文案；原声双语字幕属于另一输出版本，不把两套字幕
  同时堆叠到画面上。
