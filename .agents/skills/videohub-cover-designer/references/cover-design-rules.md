# 封面设计规则

## 信息优先级

1. 剧名或视频主题：个人主页小图中必须可读。
2. 集数：使用独立色块和大号数字，连续剧不得藏在小字中。
3. 本集看点：最多两行，每行尽量 4-8 个汉字。
4. 分类信息：只作辅助，可在小图中牺牲。

## 素材选择

- 优先使用用户提供的剧照、官方剧照或原片干净画面。
- 人物脸部清楚，眼神或动作能表达本集冲突。
- 避开源视频硬字幕、平台水印、播放器控件和大面积黑场。
- 同一系列优先复用同一底图；需要换图时仍保持字体、颜色、徽标和信息位置一致。

## 构图

- 竖版：人物占上部约 60%，下部深色信息区；集数徽标位于上方安全区。
- 横版：人物放在一侧，另一侧使用深色信息区；不要简单拉伸竖版。
- 人物眼睛、表情、枪口、手势等叙事重点不得被文字覆盖。
- 3:4 与 4:3 是独立平台画幅，必须分别构图，不能只把 9:16 或 16:9 等比缩放后强行裁切。

## 字体和颜色

- 默认使用 Windows 微软雅黑粗体；不存在时回退到黑体或 Arial。
- 主标题使用高亮色，钩子使用白色，背景使用接近黑色的半透明区域。
- 集数徽标使用高对比纯色，不使用低对比渐变。
- 文本无法在安全宽度内放下时自动缩小；低于最小字号仍放不下时应缩短文案，不应挤压字距。

## 视觉 QA

- 打开 3:4、4:3 和缩略图预览，不以脚本成功作为视觉通过。
- 检查剧名、集数、人物脸部、文字换行、画幅边缘和水印。
- 对系列封面并排比较，确认集数易找且整体风格一致。
- 记录源图哈希、输出尺寸和生成参数，便于下一集复用。
