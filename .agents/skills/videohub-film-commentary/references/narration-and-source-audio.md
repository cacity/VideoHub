# 第三者旁白与影视原声

## 两条样本的共同结构

本规则来自两条用户提供的成片样本及同名音轨：

- 《想一个人死去》解说约 1733 秒。6 秒滑窗语言检测与画面抽查识别出约 72 秒日语
  原声候选，约占 4.2%。
- 《东京出租车》解说约 1424 秒。相同方法识别出约 90 秒日语原声候选，约占 6.3%。

这些比例是对已经混合完成的样本做的近似分析，不是平台标准。两份 TXT 都是无时间戳
的自动转写，包含识别错误；结论同时参考了带时间轴 Whisper 转写、中日语声学窗口和
候选画面，不能把错字或重复词当成写作风格。

样本都由第三者旁白承担绝大多数剧情。原声集中在：

- 女主直接说出“想独自生活、体面告别”的核心选择。
- 带有反差的内心祈求、办公室争执和尴尬短问答等喜剧节点。
- 妻子追问乘客身份的短对话，快速建立夫妻关系和人物性格。
- 老人确认对方是否会再来，以及司机作出承诺的情绪伏笔。
- 能体现演员停顿、语气、亲密感或告别意味的双人场景。

## 旁白负责什么

| 内容 | 为什么使用第三者旁白 |
| --- | --- |
| 人物身份、家庭和经济处境 | 能在几秒内建立理解，不必保留低信息对白 |
| 多年经历、时代背景、支线关系 | 原片常分散在多场戏中，旁白适合压缩 |
| 行动过程和地点转换 | 画面已经表达动作，旁白只补充因果 |
| 重复争论和同义对白 | 保留结论即可，避免节奏停滞 |
| 伏笔回收与结果影响 | 帮助观众连接前后事件，但不能提前泄露关键表演 |
| 主题解释和现实延伸 | 放在剧情证据之后，明确这是解说者的归纳 |

旁白句式应以人物行动和因果为中心：谁做了什么、为什么、造成什么变化。少用连续的
“他很难过”“她很感动”替观众解释表情；画面能表达的情绪，让画面先说。

## 原声负责什么

对候选原声按以下五项各打 0-2 分：

1. **剧情不可替代性**：这句话是否改变关系、目标或结果。
2. **表演价值**：语气、停顿、表情或环境声是否承载了文字外的信息。
3. **人物辨识度**：是否能让观众听见角色独特的性格和关系。
4. **记忆价值**：是否是主题句、笑点、承诺、告白、反问或告别。
5. **可理解性**：收音是否清楚，外语是否能提供可靠字幕。

总分达到 7 分时优先保留；5-6 分需要看节奏；低于 5 分通常由旁白概括。任何原声都
必须有证据引用，不能只因台词“听起来有感觉”而脱离剧情。

## 常见切换模板

### 冲突

旁白交代矛盾来源 -> 保留最尖锐的一问一答 -> 反应镜头或短停顿 -> 旁白说明冲突后果。

### 决定

旁白压缩角色此前的犹豫 -> 原声给出决定或拒绝 -> 保留 0.3-1.0 秒表情/环境声 ->
旁白进入下一事件。

### 情绪峰值

旁白只提供理解这场戏所需的最低背景 -> 原声保留告白、承诺、和解或告别 -> 不立刻
解释台词含义 -> 下一镜头后再做轻度回收。

### 喜剧

旁白建立正常预期 -> 原声给出反差、误会或吐槽 -> 保留对方反应 -> 立即推进剧情，
不要再次复述笑点。

## 节奏和音频

- 4 分钟成片通常使用 4-8 个原声锚点，总占比先以 5%-12%试排。
- 单个锚点优先 2-10 秒；核心对话可以更长，但超过 20 秒要检查是否可压缩。
- 旁白前后不要咬住原声首尾。至少留出自然换气，情绪戏可多留 0.3-1.0 秒。
- 旁白期间原片音量默认 0.30，用于保留环境声和音乐；原声锚点恢复 1.00。
- 原声锚点内不播放 TTS。必要时先调整旁白文本和时间，不用音量竞争掩盖冲突。
- 外语原声优先显示双语字幕；屏幕空间不足时至少显示准确中文译文。

## 避免的问题

- 旁白把所有情绪说尽，随后再播放表达同一件事的原声。
- 原声片段过多，成片退化为带少量串词的剧情拼接。
- 为追求“金句”打乱因果，造成角色动机与原片不一致。
- 用长篇原声解释设定，迫使观众读大量字幕。
- 原声与 TTS 同时说话，或字幕仍显示上一条旁白。
- 在悬念揭示前由旁白提前宣布答案。
