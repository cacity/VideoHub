# VideoHub v0.8.0 更新说明

更新日期：2026-11-25。前一版本：v0.7.0。

## 本次更新

- **字幕布局与阅读**：文稿可放右侧或下方，左右宽度支持拖动调整；可一键收起工具栏，当前句始终置顶跟随。画面字幕支持字号、上下偏移和中英字号差，文稿可单独调整字号与句组间距，显示设置按视频保存。
- **资料库与视频截取**：按工程或父目录分组，折叠状态在浏览器中记忆；学习资料可移出，重新导入后恢复记录。桌面和学习页均可设置起止点，导出独立 MP4，保留原视频。
- **启动与转录**：将模型加载延后到实际任务，缩短开窗等待；修复首次转录时的日志转发与依赖导入冲突。“在线视频”统一使用“转录并生成字幕”，兼容旧选项；修复片尾少量字幕超时导致的导入失败。
- **抖音备用来源**：公开单视频按 F2 → DLPanda → HelloTik 依次解析；DLPanda 已解析但媒体地址失效时也可继续 HelloTik。保留作品身份校验、有限重试和残片清理，第三方解析及媒体请求不发送用户的抖音 Cookie。

## 升级

更新源码后重启 VideoHub 与学习服务，再 Ctrl+F5 刷新学习页。首次转录仍需加载模型。前端源码有变化，自行部署时请在 `frontend/` 执行 `npm ci` 和 `npm run build`。

本次为源码更新，现有 EXE 安装包、GitHub Release 和官网发布单独进行。视频截取需要可用的 FFmpeg。

## 验证与限制

提交前的测试、构建和验证记录见[开发日志](./development_log.md)。字幕布局已使用隔离素材完成桌面、全屏和窄屏检查；HelloTik 已完成真实单视频解析、下载和完整解码验证。AI/网络替身测试不代表真实服务质量或所有设备均已验收。

HelloTik 使用网页内部协议，网站改版或限流可能影响可用性；主页批量下载仍使用 F2。遇到登录或点数要求会停止并提示。[站方条款](https://www.hellotik.app/zh/terms)限个人用途，商业接入需另行取得授权。
