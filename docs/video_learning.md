# 视频学习

VideoHub 的本地网页学习入口，支持视频工程导入、双语滚动字幕、视频问答、时间戳笔记和联网补充。此功能属于源码版本；已有 EXE 不会自动包含本次修改。

## 启动

在仓库根目录安装现有 Python 依赖，然后构建前端：

```powershell
cd frontend
npm ci
npm run build
cd ..
python -m src.learning_server
```

打开 `http://127.0.0.1:8767/learn`。也可运行 `python src/learning_server.py`。学习服务不要求桌面窗口保持打开，也不会在打开页面时加载 Torch、Whisper 或 Kokoro。

源码桌面端 `python main.py` 新增“视频学习”标签页，可打开资料库、选择单个视频，或选择视频工程目录。在线视频页的“进入视频学习”会优先打开当前链接对应的已下载视频；下载历史页可将所选作品直接送入学习页。

端口与数据目录可自行指定：

```powershell
python -m src.learning_server --port 8768 --data "F:/my_learning_data"
```

桌面内置入口默认使用 8767。若端口被其他应用占用，会显示明确提示；改端口启动后请直接访问相应 URL。

## 一个目录就是一个学习工程

在线视频中的 YouTube 单视频、批量和播放列表处理，勾选“下载视频”后，会自动建立 `workspace/learning/projects/<视频ID>/`。原片放在工程根目录，原生字幕和翻译字幕放在 `subtitles/`，音频、转写、摘要和带字幕成片分别放在工程内的对应子目录；同时生成 `videohub_learning.json`。重复下载会复用已有工程，不再将本次字幕输出到公共字幕目录。

从下载历史或网页“下载记录”打开旧下载时，也会自动整理对应字幕。整理采用复制并校验，保留旧文件；已有工程则直接复用。页面会显示工程目录。同名而内容不同的文件会报错，避免覆盖资料。仅下载音频和其他平台现有处理流程保持各自的输出方式。

推荐目录：

```text
my_lesson/
  lesson.mp4
  lesson.en.srt
  lesson.zh-CN.srt
  lesson.ja.vtt          # 可选的其他语言
  subtitles/            # 字幕也可放在这个子目录
  videohub_learning.json # 首次导入时自动生成
```

在“导入视频 → 视频工程（目录）”粘贴这个目录，或使用桌面端“打开视频工程目录”。只有一个视频时自动读取目录和 `subtitles/` 内的所有可用字幕，不要求字幕与视频严格同名。

- 支持 SRT、VTT、ASS、SSA。根据文件名和文本推断语言，优先采用独立的英文原文与中文字幕；保留其他语言/版本供轨道选择。
- 带 Primary/Secondary 等明确样式的双语 ASS，以及持续使用独立英文/中文行的双语 SRT/VTT，会拆成原文和译文两个轨道，避免英文重复显示；译文优先使用 polished 版本。只有中文素材时可将中文作为原文使用。
- 同目录有多个视频时先选择本次视频，只自动关联同名字幕。长期使用建议每个视频一个目录。
- 字幕须属于所选视频。平台字幕片尾偶尔会延长：只要每句都从视频内开始，且最晚结束时间超出不超过5秒，学习库会将超出部分的结束点对齐片尾，并显示可展开的校正提示；原字幕文件不改动。超出超过5秒，或存在从片尾之后开始的句子时，仍拒绝导入，并提示具体文件及超出秒数。
- 工程清单采用相对文件路径。目录整体移动后，在同一本地学习库重新打开可按工程 ID 保留笔记和进度；如视频内容已经不同，不能冒用原工程 ID。
- 清单不可写时，视频仍可登记到本机资料库，并提示未保存清单。清单不包含密钥。

也可以切换“单个视频 / 下载记录”导入单文件，并手动关联字幕。普通本地视频直接引用，下载历史中的文件按上述规则整理为工程；源文件移动、替换后需要重新打开工程或导入。

## 观看与字幕

### 独立字幕文件与页面样式

新转写及双语翻译会同时保存不带显示样式的原文、译文 SRT，例如 `lesson.source.en.<内容标识>.srt`、`lesson_polished.target.zh-CN.<内容标识>.srt`。语言代码按实际选择保存；内容标识区分版本，内容相同则复用。原有中英混排 SRT/VTT/ASS 仍保留，供烧录和其他工具使用。独立文件优先用于学习，同语言有多个版本时优先润色版并保留备选。

已有双语字幕不需要重新翻译。学习页打开视频时，会把已登记的原文与译文分别导出至工程 `subtitles/learning_tracks/`；单视频或工程不可写时回退到 `workspace/learning/subtitles/<学习视频ID>/`（指定 `--data` 时在对应学习库内）。原文件、笔记、字幕引用和播放进度保留，自动副本不覆盖同名已修改文件。对自动副本作手工修改后，需要重新导入才能更新学习库中的字幕。

播放器下方展开“字幕文件与样式”：

- 分别下载当前原文、译文的 SRT；轨道下拉框按原文/译文角色筛选，版本保留。
- 用原有“画面字幕”选择英文、中文、双语或关闭，“字号”调整大小。
- 设置字体、原文与译文颜色、黑色背景深度、行距、粗体、描边阴影和顶部/底部位置；可一键恢复默认样式。

样式按视频保存在本机学习数据库，刷新或服务重启后恢复，普通和全屏画面共用；只影响画面字幕，不改变字幕文本、时码、下方文稿或已经烧录的成片。系统安装字体与浏览器支持会影响实际字体。当前新增面板已通过构建和接口验证，自动浏览器被访问策略拦截，尚未完成本轮视觉验收。

### 播放与阅读

学习页与播放器全屏中支持以下快捷键，无需先点击视频。播放器下方“快捷键”可以展开查看说明，倍速、字幕与静音操作会显示短暂提示。

| 按键 | 操作 |
| --- | --- |
| `F` | 全屏 / 退出全屏；`Esc` 仍可由浏览器退出全屏 |
| `C` | 加速0.1×，最高3× |
| `X` | 减速0.1×，最低0.25× |
| `S` | 隐藏 / 显示画面字幕，恢复本页中该视频上次显示的语言 |
| 空格 | 播放 / 暂停 |
| `←` / `→` | 后退 / 前进5秒，取消逐句循环，不超出视频边界 |
| `M` | 静音 / 取消静音 |

大小写字母均可用；按住不连续触发。中文输入法开启时，在播放器等非文本区域仍可用物理字母键控制。输入问题、笔记、搜索文字、数字等可编辑内容时不触发；自定义文本/组合控件、弹窗及 `Ctrl` / `Alt` / `Meta` 组合键保留原操作。倍速/字幕选择框、字号滑块和复选框保留空格/方向键，字母快捷键仍可控制视频；按钮、链接、折叠说明和布局拖动条上的空格/方向键也保留。导入窗口打开时停用视频快捷键。需要明确恢复播放器焦点时，展开“快捷键”，点击“点击这里启用快捷键”，画面会显示已启用提示。

倍速和画面字幕显示状态沿用本机进度保存；倍速菜单同步显示1.1×、1.2×等当前值。`S` 不隐藏下方字幕文稿；刷新后如果字幕原本关闭且本页尚无上次语言，按已有轨道选择双语、原文或译文。浏览器页面未获得键盘焦点、焦点在地址栏或其他应用时，快捷键不会生效。

如出现无响应，可展开“快捷键”→“检测按键是否收到”，点击画面后按一次 `C`，查看是否收到按键、是否被提前阻止，以及焦点是否在输入框。检测仅在页面内临时显示，文字输入内容会省略，不写入学习库、不发送至AI或服务器。全屏失败也会在画面提示原因。2026-10-28用户已在Edge实际确认C/X/S/F均可用；控制台中的浏览器扩展日志本身不足以确定拦截来源。

画面只使用当前选中的原文轨道和译文轨道，SRT/VTT/ASS 等其他版本作为备选，不同时叠加。原文和译文分别按各自时间轴显示；同一轨道出现滚动字幕重叠时，画面取最新开始且仍有效的一句，双语模式每种语言最多显示一个字幕块，长句自然换行。译文尚未开始或已结束时不提前/延后显示。下方文稿保留全部句子及按时间关联的译文，便于阅读、问答和引用。

播放器按原片实际比例同时约束宽高，避免“宽度铺满、高度单独截断”造成额外左右黑边；不裁切、不拉伸原片。长文件名会自动换行，不撑宽页面。视频本身已经编码进去的黑边不在此处移除。

视频标题默认缩小为16px（窄屏15px），最多显示两行，悬停可查看完整标题。左侧资料库每个视频只占一行，长标题以省略号收起，悬停可查看完整标题和播放进度，行底保留细进度条。

顶部“资料库”和“学习助手”按钮可分别折叠/展开左右侧栏；折叠状态在当前浏览器中记忆，折叠不会清除未发送的问题、笔记草稿或停止正在执行的问答任务。未手动指定播放器高度时，折叠学习助手会采用更大的默认画面。

拖动左侧资料库的右边界、右侧学习助手的左边界，可以分别调整侧栏宽度；拖动播放器下方的横向拖动条，可以上下调整画面高度，视频宽度按原片比例同步变化。尺寸保存在当前浏览器，刷新后恢复；窗口变窄时会自动限制尺寸，避免溢出或拉伸。双击拖动条或聚焦后按 `Enter` 恢复该处默认尺寸；方向键微调，`Shift` 加速，`Home` / `End` 调到当前允许的最小/最大值。窄屏中助手移到下方，不显示右侧横向拖动条；手机宽度时也隐藏左侧拖动条，播放器高度仍可调节。

使用画面右上角“全屏”按钮、双击画面，或聚焦播放器后按 `F`，可让视频和画面字幕一起全屏。按 `Esc`、`F` 或右上角“退出全屏”返回。全屏沿用已选的原文/中文/双语模式与字号，并按屏幕适当放大字幕；选择“关闭”时全屏也不显示字幕。需要支持 Fullscreen API 的浏览器；当前验证为桌面 Chromium，未实测 iOS 系统原生视频全屏。

画面字幕与滚动文稿的语言独立选择：原文、译文、双语、关闭。英文素材显示“英文/中文/双语”；字幕切换不改变原声语言。

点击时间戳跳转；点击字幕正文选句；右侧循环图标反复播放该句。支持倍速、字号、字幕全文搜索。滚动阅读时暂停自动跟随，“回到当前”恢复。长文稿分批显示，自动跟随会切换到当前字幕所在页。

播放位置、倍速和显示偏好保存在本机，刷新、服务重启后可恢复。视频引用、章节与导出笔记都使用原片时间轴。

浏览器不能播放某些 MKV 或编码时，在“大纲”面板选择“生成浏览器预览”。FFmpeg 创建独立的 MP4 缓存，不改写原片。媒体接口支持 Range/206，可拖动长视频。

没有原文字幕时，可在“大纲”中选择 Whisper 模型生成原文，沿用现有资源限制。首次使用相应模型可能需要下载。转写在独立进程中运行，停止操作会结束该进程；跨进程锁防止学习页和桌面端同时堆叠 Whisper。自动识别输出会校验原片边界，若裁掉越界字幕会明确警告。自动转写仍需核对人名、术语和静音处的识别结果。

## AI 与联网

在本机未提交的 `.env` 配置至少一个服务，重启学习服务或源码桌面端：

```dotenv
DEEPSEEK_API_KEY=your-own-key
# 或
MOONSHOT_API_KEY=your-own-key
```

Kimi 也接受 `KIMI_API_KEY`。可选环境变量：`DEEPSEEK_MODEL`、`DEEPSEEK_BASE_URL`、`MOONSHOT_MODEL`、`MOONSHOT_BASE_URL`、`LEARNING_INPUT_BUDGET`。页面“模型设置”可覆盖本次使用的模型名，不改变原有翻译设置；Key 不进入页面或浏览器存储。

使用“这里是什么意思”、输入自定义问题，或选一句字幕再问。自动带入播放位置与所选字幕。默认允许全片；关闭“允许引用全片”后，仅使用当前进度前的内容，历史对话也按范围过滤。

短字幕可全部进入上下文；长字幕先逐块完整分析，再组合章节提纲、当前片段、关键词相关原文和有限历史。逐块缓存依赖字幕版本、模型与提示词版本，中断后可重新发起并复用已完成块。未完成分析不会显示为全片分析成功。

引用标记由服务端核验，只有实际提供给模型的字幕 ID 才能形成可点击时间引用；无效引用被移除并给出警告。校验确认来源位置，不能保证模型解释本身一定正确。字幕无法说明图表、动作时，需要结合原视频判断；首版没有视觉模型。

联网补充默认关闭。开启后选择搜索服务即可发送问题，“联网检索词”可选：留空时使用问题前128个字符（合并空白），另填内容则以该内容为准，最多128字。发送前在输入框下方显示“本次检索”，可填写具体概念提高准确性。搜索服务只接收检索词，不接收整片字幕和笔记。一次取最多五个来源，展示链接、证据类型和检索时间。获取不到全文时按搜索摘要处理；失败时明确提示并继续依据视频回答，不自动切换另一家付费服务。

点击“发送”后，输入框旁显示“正在提交问题”，提交失败时在同处显示具体原因并保留问题，不必滚到页面顶部查找。任务创建成功后显示准备、结构分析、搜索、回答等当前进度；等待分析长字幕可能需要较长时间，可用“停止”取消。若只是刷新历史记录失败，会说明问题已经提交，无需重复发送。搜索缺少密钥、网络失败或没有结果时，完成的回答会附检索警告；这不代表已获得网页证据。

聊天模型与搜索独立：可用 DeepSeek 聊天配 Kimi 搜索，反之亦然，需要分别配置对应服务。实现使用官方 REST 搜索接口，未采用已进入迁移流程的旧 Kimi `$web_search` 路线。

官方接口参考：

- [DeepSeek Search/Fetch](https://api-docs.deepseek.com/guides/search/)
- [Kimi 搜索最佳实践](https://platform.kimi.com/docs/guide/best-practices-for-web-search)

回复逐步显示，可停止。服务返回实际 usage 时显示回答 token 数；结构分析和搜索可能额外计费，界面不把估算当成实际账单。超时、限流、余额不足和缺密钥会分别提示。

## 笔记与备份

“笔记”支持手写、选句摘录、收藏已完成的 AI 回答、编辑、删除、标签和 Markdown 导出。引用保留创建时的字幕文本和版本；字幕更新后会提示旧版来源。并发编辑通过版本检查避免覆盖另一页面的修改。

导出包含时间码、视频回看链接、字幕摘录与网页出处。链接依赖本机学习服务运行；即使离线阅读也保留时间码。导出不自动写入 Obsidian。

数据默认位于 `workspace/learning/learning.sqlite3`，缓存位于 `workspace/learning/cache/`。笔记库未加入普通媒体清理选项。备份时应先停止学习服务，再复制整个学习数据目录，避免遗漏 SQLite WAL 中尚未合并的数据。

工程目录中的清单携带素材关联；聊天、笔记和进度仍保存在本机学习库。把素材目录带到另一台电脑不会自动带走笔记，应同时迁移学习数据目录或导出 Markdown。

```powershell
python -m src.learning_server --dev-origin http://localhost:5173
# 另一个终端
cd frontend
npm run dev
```

开发页访问 `http://localhost:5173/learning.html`。显式允许本机 Vite 来源；生产默认拒绝跨站请求，写操作需要本地会话令牌。

`tests/test_learning.py` 覆盖字幕、工程、引用、缓存、任务恢复、笔记、来源隔离等；`tests/test_resource_policy.py` 验证线程与进程互斥。真实调用、媒体解码、桌面和浏览器验收记录在本地 `workspace/project082_video_learning/`，不包含凭据。

当前已完成六阶段首版，真实验证了 DeepSeek 问答/大纲/翻译/搜索、Whisper tiny、预览转码与浏览器操作。Kimi 未配置密钥，只有适配协议与失败路径测试，未宣称真实联调通过。未制作新 EXE、部署公共网站或实现跨设备同步。
