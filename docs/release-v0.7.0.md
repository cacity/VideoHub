# VideoHub v0.7.0 更新说明

更新日期：2026-11-06。前一版本：v0.6.0。

本说明汇总当前v0.7.0源码更新。会议翻译与录屏已通过[PR #22](https://github.com/cacity/VideoHub/pull/22)合并；本次补充多视频学习、助手恢复、面板调宽、抖音系列下载与本地文件统一入口。本文描述源码功能，GitHub Release、EXE安装包及官网发布单独进行。

## 会议翻译与录屏

- Windows桌面新增“会议翻译与录屏”入口，通过可选独立环境运行，可复用已有MeetingCaption环境与本地模型。
- 选择整屏或固定区域、系统声音设备及保存目录，三秒可取消倒计时后开始；支持时长显示、托盘停止及未完成媒体的恢复封装。区域坐标使用物理像素。
- 可选英文/中文实时字幕，使用本地识别与翻译模型或DeepSeek翻译。字幕处理与原始录制分离，字幕过载或翻译失败不影响原始录制；原声写入故障明确标记中断并保留媒体。
- 停止后生成MP4、独立中英文SRT及学习工程。可使用完整原声会后重新转写和翻译，保留旧字幕，再进入学习页问答、记笔记、生成大纲和脑图。
- 首版不采集麦克风，不支持暂停续录。安装、模型配置、数据发送及操作细节见[会议录屏指南](./meeting_recorder.md)。

## 学习流程完善

- 同一目录可复选导入多个视频，默认全选；字幕按视频同名匹配。各视频分别保存身份、进度、笔记、AI记录与字幕版本，部分导入失败不丢失成功结果。
- 集合清单兼容旧单视频工程；同一本机学习库中移动目录后可恢复记录。目录扫描当前支持根层最多200个视频，每视频最多80份字幕文件；同名歧义会提示处理。
- 对话和脑图的失败原因刷新后仍可查看；失败回答按原问题的时间、范围、选句和联网设置重试，使用当前所选模型，不重复新增用户问题，也不清空新草稿。
- 全片分析遇到结构化输出截断时，在同模型上增加输出额度并只重试一次；复用已完成章节。脑图重新生成失败保留上一份有效图。
- 右侧助手上限从560像素/窗口36%调整为最多窗口80%，同时扣除可见资料库并为视频区保留至少320像素；恢复已保存宽度，窄屏仍使用上下布局。
- 已有英文字幕补翻译、原文/译文独立存储和历史版本选择继续保留。具体流程见[视频学习指南](./video_learning.md)。

## 本地文件统一入口

- 本地视频、音频和文本合并为一个“本地文件”标签，根据文件扩展名或目录自动识别，支持手动选择类型。
- 共用处理选项、按钮和日志，按类型显示所需功能。保留视频目录批处理、源/目标语言、字幕烧录、剧集项目模式和歌曲音频提取；文本直接生成摘要。
- 路径/类型错误会提示，运行时锁定输入并防止重复启动，任务完成、失败或中断后恢复操作。

## 抖音下载与诊断

- 媒体返回401/403/404/410或HTML时，尝试备用地址，仍失败则重新解析并重试一次；校验仍为同一作品，失败清理残片，有明确长度的未压缩响应校验大小。
- 文件名为完整作品ID保留空间，避免同名系列或长标题误判已下载。需要字幕/转写/摘要的抖音单视频直接建立学习工程，原片和产物统一保存；纯下载沿用所选目录，旧无身份文件保留且可能需重下。
- F2返回403后，相同配置在当前进程暂停尝试15分钟，跨新下载器有效，公开单视频继续用DLPanda；到期或Cookie/代理变更后可再试。
- 日志区分解析与文件保存，带作品标识、实际来源、保存路径和本地复用状态；不打印完整签名URL或F2内部重复QA提示。
- 本轮没有升级F2，不能据此认定平台403已解决；真实失败作品仍需现场重试。

## 升级与验证

1. 更新源码后重启VideoHub，再Ctrl+F5刷新学习页；已有EXE需另行重新打包。
2. 在“会议翻译与录屏”按指南配置独立环境及模型，首次使用先做短录制，检查声音、区域和字幕。
3. 多视频学习时选择目录并确认复选列表；AI失败后可在回答或脑图处重试。

本次提交前验证：173项Python/Qt检查、44项前端测试、TypeScript/Vite生产构建及24个暂存Python源码编译通过。仅从Git暂存区导出跟踪前端源码后，干净安装依赖，44项测试及构建也通过。Ruff F/E9相对原提交无新增诊断，既有问题保留；网络、媒体及AI用替身，Qt和网页分别采用隔离表单与DOM检查。

此前会议分支另有6项隔离Qt检查通过。实际FFmpeg短录制使用17.3秒合成画面和注入语音，音视频均17.3秒，本地模型生成5对完整字幕并完成学习导入。一小时合成媒体封装验证音视频均3600秒；不等同于一小时真实设备耐久测试，本次提交前未重复进行设备采集。

本次更新包含源码、测试和版本文档；未调用真实付费模型。真实会议长时WASAPI、多屏DPI/驱动、付费AI质量、学习页面浏览器视觉及重启后的快捷键稳定性仍需现场验收。详细记录见[开发日志](./development_log.md)。
