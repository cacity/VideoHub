# VideoHub v0.8.1 更新说明

更新日期：2026-11-27。前一版本：v0.8.0。

## 本次更新

- 新增 PeanutDL 作为抖音备用来源，视频与图集依次使用 F2、DLPanda、HelloTik、PeanutDL。解析或媒体地址失败后有限回退，第三方请求不携带用户的抖音 Cookie。
- 支持图文分享短链及 `/note/` 链接，保存整组图片；同时返回图片和合成视频时优先图片，只返回视频的图集来源会跳过。图集无需视频转录或学习工程导入。
- 图片按001起编号，经完整解码确定JPEG、WebP、PNG等真实格式，保留实际扩展名。每张失败先试备用地址，再尝试后续来源；切源校验作品身份、图集类型与数量，缺图不报完成。
- 图片保存到所选目录的 `<标题_作品ID>_images/<来源>/`，不同来源独立保存。重复下载验证并复用有效图片，失败保留已完成图片供续跑，全部完成后生成 `gallery.json` 数量清单。
- CLI与桌面提示显示图片类型及已保存/总张数，修复首图误识别为视频、缩略图混入图集和进程内来源健康状态的测试隔离问题。

## 验证与升级

用户提供的10张图集已通过PeanutDL与HelloTik完整下载验证：PeanutDL为长边3240像素的WebP，HelloTik为横图1920×1280、竖图1440×2160的JPEG。本样本DLPanda只提供合成视频、F2返回403；不代表每个来源对所有图集均可用。相关回归及提交验证见[开发日志](./development_log.md)。

更新源码后重启VideoHub。已有EXE安装包、官网与GitHub Release不随本次源码推送自动更新。第三方网页接口可能随网站改版变化；遇到验证码、登录、点数或限流要求会停止该来源，站点使用范围以各自条款为准。
