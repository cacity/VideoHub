# VideoHub v0.6.0 更新说明

更新日期：2026-11-02。前一版本：v0.5.0。

当前状态：源码版更新，尚未重新打包EXE或创建GitHub Release。版本号与文档更新不代表已提交、推送或发布。

## 版本重点

本版将下载、字幕与后续学习连成一条流程：一个视频作为一个工程，既能边看边读双语字幕、询问AI、记录笔记，也能把整个视频整理为章节和脑图。下载时没有翻译的英文字幕，可以稍后在学习页选定版本单独翻译。

## 学习工程与播放器

- 桌面“视频学习”、在线视频和下载历史均可进入网页学习页，默认地址为 `http://127.0.0.1:8767/learn`。
- 一个视频与多份字幕可作为目录工程导入。YouTube单视频、批量和播放列表在下载完整视频时自动保存到 `workspace/learning/projects/<视频ID>/`，相关字幕、音频、转写、摘要和带字幕成片留在工程内。
- 工程清单使用相对路径；旧下载按既有流程复制整理，保留原文件。学习记录中的身份、进度与笔记随重新打开工程保留。
- 全屏播放包含字幕；左右栏可独立折叠、拖动调宽，视频高度可拖动并保持画面比例。资料列表名称单行显示，长标题省略。
- 保存播放进度、倍速、字幕显示和样式偏好；支持字幕搜索、时间跳转、逐句选择和循环。

## 多语言、补翻译与版本管理

- 原文和译文分别保存纯文本SRT，同时保留已有双语文件，供烧录等流程使用。
- 在播放器选择原文、中文、双语或隐藏；设置字号、字体、颜色、背景、行距、粗体、描边和字幕位置。普通/全屏共用设置，不改写字幕文本或已烧录画面。
- 学习页展开“字幕版本”，分别选择原文与译文；可查找工程目录、旧公共字幕目录和本机学习副本中的SRT/VTT/ASS/SSA。双语文件提供两种语言的复用动作。
- 点击“重新查找字幕”发现后来新增的文件；文件名、语言、格式、日期和路径帮助区分版本。其他位置的文件可手动导入。
- 选择原文版本后点击“翻译已有字幕”，确认DeepSeek/Kimi配置，再开始生成中文字幕。无需重新下载或转写；保留时码，提供进度、停止和失败提示。
- 替换字幕和重新翻译保留可选择的历史版本；重新打开工程保留当前选轨。翻译失败、取消或原文中途变化时保留旧译文，避免保存过期结果。

## AI、笔记、大纲与脑图

- DeepSeek/Kimi可依据全片字幕、当前进度或选句回答，字幕引用可跳回原片；全片长字幕分段处理并复用分析缓存。
- “联网补充”的检索词可留空，默认使用问题前128字；页面显示提交状态和失败原因，失败保留草稿。
- 手动笔记、字幕摘录和AI回答可保存为带时间戳的笔记，支持标签、编辑及Markdown导出。
- 生成章节大纲，按章节定位视频。
- 在“AI对话 / 笔记 / 大纲”之后新增“脑图”。结构明确时组织逻辑图，多话题素材生成主题图并说明；支持分支折叠、缩放、大图、节点时间跳转和Markdown/JSON导出。
- AI历史回复、流式内容及笔记渲染Markdown标题、列表、表格、引用和代码块，保留可验证的字幕引用；不执行模型返回的HTML或危险链接，不自动加载外链图片。

## 近期修复

- 修复全屏时字幕消失，以及播放器容器产生额外两侧留白的问题。
- 分离双语轨道，避免不同格式、原文或译文在画面上重复叠加。
- 对不超过5秒且每句均从视频内开始的片尾字幕延长，在学习库中对齐片尾并提示；明显错片或越界文件仍拒绝导入，原文件保留。
- 修复字幕下拉框在保存进度期间恢复旧值，导致所选版本未生效的问题。
- `C/X`每步加减速0.1×、方向键每步跳转5秒，并支持受控的长按重复；`F/S/M/空格`长按只切换一次，编辑区和组合键保持原行为。
- 加固重开页面的加载和快捷键事件入口，增加仅收到松开事件时的播放器内补偿及独立“页面自检”。最新用户已确认C恢复；其他键与再次重启后的稳定性仍待本轮现场确认。

## 升级与使用

1. 按现有Python环境安装依赖。在仓库根目录运行 `cd frontend`、`npm ci`、`npm run build`，然后回到仓库根目录。
2. 重启源码桌面程序 `python main.py`，或独立启动 `python -m src.learning_server`。打开学习页后按Ctrl+F5刷新。
3. 已有英文字幕补翻译路径：**字幕版本 → 选择原文 → 翻译已有字幕 → 确认AI服务/模型 → 开始翻译为中文**。
4. 已有EXE不会包含源码修改，需要重新打包；本次未生成安装包。字幕样式只能调整外挂字幕，不能改变视频内已经烧录的字幕。

字幕、进度、笔记和设置保存在本机学习库；跨机器使用需迁移学习库或导出笔记。AI操作会向所选服务发送相关字幕/问题，需要既有密钥配置；不会在打开学习页时自动开始翻译。
